# Reporting

Native list, search, graph, and pivot views operate on stored deputation fields. Dimensions include department, destination, status, active step, activity type, requester, administrative officer, and date grouping. Measures include case count, participant count, duration days, and processing duration hours.

The Government Deputation Register lists case reference, outgoing registration, subject, department, destination, period, duration, participant count, and status. Native export is the V1 spreadsheet path. No custom JavaScript dashboard or invented financial measure is included.

Processing duration is populated when issuance completes. It is blank before completion and therefore is not presented as a reliable completed-cycle measure for pending cases.
